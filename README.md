# Bulls and cows Python game
# Description
That is famous math guessing game, where you should guess numbers! Made it, cause it was set by my IT courses teacher, as a homework project on IT courses called "IT STEP".
# Features
  - Currently no special features, cause it is only my homework project. BUT i excepted errors that is causing cause of the String inputs instead of numbers(integers)
# Tech Stack
it was created in Python 3.14.7, and using Python library called "Random".
# Installation Process
  - Clone this repository using cli tool called "git":
    
        git clone https://github.com/ruslanmatkovskyi/bulls-cows-game.git
# Running Process
  - To run my programm, you need to go to the repositories directory:
    
        cd bulls-cows-game
    
  - And run python command to start the game:
    
        python game.py
